# Contributing

Thanks for helping improve Workflow Looper.

1. Open an issue describing the behavior or focused change.
2. Create a branch from `main`.
3. Keep changes scoped and add self-test coverage for detector or automation behavior.
4. Run `dotnet build .\WorkflowLooper.sln -c Release`, the xUnit project, and the published executable self-test.
5. Open a pull request with the test output and before/after UI images when visual behavior changes.

Do not include credentials, private paths, captured game frames, or unrelated generated output in a pull request.
